## ⚙️ La ingeniería detrás de este portafolio

Este sitio no es solo una vitrina — es una muestra en vivo de cómo trabajo.

- **Arquitectura:** SPA construida con **React + Vite** en vez de un framework con SSR, porque un
  portafolio estático no necesita servidor: el resultado es un bundle liviano, tiempos de carga
  instantáneos y despliegue trivial en un CDN estático (Netlify).
- **UI/UX & Animaciones:** microinteracciones con **Framer Motion**, cursor magnético en elementos
  interactivos, tarjetas 3D personalizadas y modales **"Cómo lo hice"** por proyecto — con z-index y
  foco (focus trap) controlados explícitamente para no romper la navegación por teclado ni superponerse
  con la navbar.
- **Estilos:** **Tailwind CSS** sobre una librería de componentes propia (`src/components/ui/`), modular
  y reutilizable, sin CSS duplicado entre secciones.
- **Contenido y activos:** todo el texto vive centralizado y desacoplado de los componentes en
  `src/data/content.ts` (bilingüe ES/EN); imágenes, capturas y el CV se sirven como activos estáticos
  optimizados desde `/public/`, sin llamadas a un backend.

> El código fuente completo vive en la carpeta [`kristopher-dev/`](./kristopher-dev) de este repositorio.
